# Github-General-Task

This repository contains a simple C++ program (`main.cpp`) written for a GitHub practice task.

## What it does

The program is a **Simple Calculator** that can perform basic arithmetic operations:
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

It interactively asks the user for two numbers and an operator, and then displays the calculated result. It also handles basic errors, such as division by zero.

## How to run it

To compile and run this code, you will need a C++ compiler like `g++` or `clang++`. 

1. **Compile the code:**
   ```bash
   g++ main.cpp -o main
   ```

2. **Run the executable:**
   ```bash
   ./main
   ```

   **Example Usage:**
   ```
   Hello! My name is Ahmad and this is my Github Practice Task.
   
   --- Simple Calculator ---
   Enter first number: 10
   Enter operator (+, -, *, /): *
   Enter second number: 5
   
   Result: 10 * 5 = 50
   ```
